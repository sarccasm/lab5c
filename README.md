# Shopping system — Practice 4 EFC

Реалізація https://github.com/ChNU-Classes/Practical-Labs-EFC на основі наявного ProductsValidation MVC-проєкту.

## Запуск

Потрібен .NET SDK 9.

```sh
dotnet restore
dotnet run --no-launch-profile --urls http://localhost:5080
```

Відкрити http://localhost:5080. SQLite-база `shopping.db` та демонстраційні записи створюються автоматично при першому запуску. Дані зберігаються між перезапусками.

## Реалізовано

- ShoppingContext: Products, Customers, Supermarkets, Orders, OrderDetails; ключі, зв’язки та обмеження видалення.
- CRUD товарів, покупців, супермаркетів і замовлень. Рядки замовлення додаються, змінюються та видаляються через форму замовлення.
- Пошук покупців за підрядком імені або прізвища; сортування прізвища/адреси в обох напрямках.
- Пагінація супермаркетів по 5 записів.
- Вибір покупця й супермаркету за назвами, товарів із ціною та дробовою кількістю.
- Деталі замовлення: товари, кількість, ціна та загальна сума. Ціна фіксується при додаванні товару до замовлення; знижка покупця зберігається як поле за схемою, але не застосовується до суми.
- Валідація форм, antiforgery для змін даних; видалення довідникових записів, що використовуються в замовленнях, блокується.
- Попередні Users та редагування цін за категоріями збережені. Users залишаються демонстраційними даними старої роботи в пам’яті.

## SQL Server

У `appsettings.json` змінити `DatabaseProvider` на `SqlServer` та встановити `ConnectionStrings:SqlServer` для свого сервера. LocalDB доступний лише на Windows; на macOS потрібен доступний SQL Server. Для чистої БД таблиці створюються через `EnsureCreated`; міграції в цій реалізації не використовуються. Для зміни схеми наявної БД слід перейти на міграції або створити нову базу.
